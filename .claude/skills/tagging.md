# Tag Management Skill

当用户要求导入微信读书笔记、重新打标签、批量整理标签时，使用此 Skill。

## 标签分类体系（优先使用，但不强制）

以下分类体系是标签的**首选来源**。大部分笔记应该从这里选标签，
但如果笔记内容有明确独特主题（如"苏轼""记账""美股"），
也可以用体系外的标签——但要确保这类标签确实是体系无法覆盖的。

- **生产力**：#效率 / #决策 / #习惯 / #学习 / #目标 / #专注 / #笔记术
- **心理**：#认知偏误 / #情绪 / #动机 / #自我认同 / #焦虑 / #社交 / #斯多葛
- **财富**：#投资 / #记账 / #商业 / #极简消费
- **人文**：#哲学 / #历史 / #文学 / #古诗 / #写作 / #社会学
- **生活**：#健康 / #关系 / #收纳 / #日常 / #早起 / #拖延
- **科技**：#AI / #编程 / #产品 / #工具
- **读书**：#书评 / #金句 / #书单 / #精读

## 打标原则

- **优先体系内**：能在体系内找到的，用体系内的
- **可越界**：体系确实没有合适标签时，用一个简短的体系外标签
- **宁缺毋滥**：找不到合适的就少打，不要硬塞
- **一致性**：同一条笔记的同一主题，不同批次/不同时间打标结果应该相同

## 微信读书导入

```
1. 调用 flomo_import_weread(batch_size=15)
2. 读返回的每条划线+书评
3. 过滤：以下类型的书评直接跳过，不导入：
   - 纠错型：只是指出书中笔误/错误（如"这里写错了，应该是...才对"）
   - 复述型：只是把划线换种说法重述一遍，没有新思考（如划线是"y=exp(x)"，书评是"y=eˣ"）
   - 灌水型：内容 < 5 个字且无实质观点
4. 从分类体系中选 1-2 个最匹配的标签（体系无合适时可自定义1个）
5. 每条必须包含 #微信读书
6. 逐条调用 flomo_create(content, tags)
   格式: #标签1 #标签2<br>划线内容 ——《书名》作者<br><br>书评内容
   顺序：标签 → 原文+书名同行 → 空行 → 书评
   注意：flomo 网页端不渲染 \n 换行，必须用 <br> 标签
7. 逐条调用 flomo_weread_mark_imported(review_id, ...)
8. 同一本书的不同划线 → 优先用相同标签
9. 重复直到 flomo_import_weread 返回空
```

## 重新打标（已有笔记）

```
1. 调用 flomo_retag(batch_size=10, source="flomo")
2. 读每条笔记和当前标签
3. 判断：
   - 原标签贴切 → 保留（即使是体系外标签）
   - 原标签粗糙/太细 → 用体系内标签替代或合并
   - 原标签错误 → 重新分配
4. 调用 flomo_tag_update(slug, tags) 逐条更新
5. 重复直到 flomo_retag 返回空
```

## 一致性要求

- 内容相似的笔记 → 相同标签
- 同一本书的微信读书划线 → 相同标签
- 不同批次/不同时间的导入 → 标签风格一致
- 不能前一条记录打#商业 后一条打#财富
- 调用 flomo_tags_taxonomy() 随时查看可用标签
