# Review Skill

生成 flomo 笔记回顾。两套流程:

- **每日复习(默认)**:间隔重复。你写**一条钩子**,不写文章。系统管节奏,你管线索。
- **主题回顾(可选)**:两阶段 LLM 深潜,从候选池里挑关联笔记做主题性回顾。

---

## 每日复习流程

```
1. flomo sync                                  # 确保本地 DB 最新
2. flomo review-daily -o /tmp/queue.json       # 看今天到期的笔记(你的原文)
3. 给每条到期笔记写一条「钩子」
4. 更新到 /tmp/queue.json
5. 逐条执行: flomo review grade <slug> <grade>   # 系统据此排下次复习
```

系统按简化 SM-2 安排节奏:新笔记在 30 天内逐步引入;复习后 `again`→1 天、`hard`→×1.3、`good`→×2、`easy`→×3(封顶 60 天)。

### 你在做什么

**钩子不是总结,是「新角度」。** 读用户自己的笔记,给出一条让他能接着想的线索。比如:

- 一条提问/反问:「这招现在还在用吗?」
- 一个新角度:「当时觉得是效率问题,现在看更像焦虑问题。」
- 一句关联:「这条和上个月那条关于专注的笔记是一回事。」

### 怎么写钩子(硬底线,出现即重写)

- 不用「这段笔记告诉我们/体现了/说明了」这类总结话术
- 不重复笔记原文,不抄金句
- 不写「底层逻辑/本质/共性/这很值得思考」这种 AI 味说教
- 不写长段。一条钩子不超过 2 行
- 用你自己的语气,像一个熟人记起这件事时随口说的话

写不出来就写「钩子:无」,别硬凑。不勉强、不凑数的钩子系统里会自然消失。

### 评分后

`flomo review grade <slug> <grade>` 输出下次复习日期。全部评完就结束,今天没有更多事了。

## 主题回顾流程(可选,深潜)

系统管每日节奏后,你想做更深入的跨笔记回顾时用这个:

```
1. flomo sync
2. flomo_review_candidates()               # Phase 1: 看所有池的概览(无全文)
3. 挑 2~5 个有潜力的池
4. 对每个池: flomo_review_pool(strategy, label)   # Phase 2: 拿该池全部笔记全文
5. 通读全文,决定分组,写回顾
6. 存到 /tmp/reviews.json
7. flomo review --push --json /tmp/reviews.json
```

⚠️ `--push` 会 DROP + CREATE 新表,**清空旧的 daily_reviews 数据**。只在你确实要换一批卡片时用。

### 4 种策略

| strategy | label 是什么 | 池里是什么 |
|----------|-------------|-----------|
| `same_book` | 书名 | 同一本书的划线/书评 |
| `tag_cluster` | 标签名 | 同一标签下的笔记 |
| `near_time` | 日期(YYYY-MM-DD) | 同一天写的笔记 |
| `co_tag` | `"A × B"`(注意 ` × ` 带空格) | 同时带两个标签的笔记 |

> 跨池组合时,`strategy` 填 `cross_pool`(代码支持,overview 里没有)。

### Phase 1 怎么挑池

`flomo_review_candidates()` 返回每个池的 `samples`(前 ~80 字)和 `tag_distribution`,**不含全文**。你在这里只做一件事:判断哪个池值得展开看全文。

**值得展开**:
- samples 之间看起来指向不同子主题,可能交叉
- 某标签很大,但 tag_distribution 显示它常和别的标签共现
- 几个不同策略的池(label)可能暗含跨池关联

**直接跳过**:
- samples 全是流水账、随手记、无信息量
- 池很大但 samples 高度同质(比如 30 条都是「今天看了篇 AI 文章」)
- 微信读书划线池里全是金句摘抄、没有你自己的书评

挑 2~5 个就够。别贪多 —— 每个池的全文你都得真的读。

### Phase 2 怎么读

`flomo_review_pool(strategy, label)` 返回该池**全部**笔记,`content` 不截断。

- `label` 必须用 Phase 1 返回的原值,一个字都不能改(co_tag 的 ` × ` 空格也别动),否则查不到返回 `null`。
- 拿到后**逐条读全文**。别只扫一眼就分组。
- 一个池读完后挑不出好组合,就跳过这个池,别硬凑。

### 分组

你是编辑。分组是这步的核心,比写作更重要。

- 找**真正有内在联系**的笔记组合,不是"主题沾边"。
- 一条笔记只能进一个分组。
- 组合不限于 2 条 —— 3 条、4 条都行,只要联系是真的。
- **大胆跨池**:Phase 2 拉了多个池的全文,不同池的笔记能搭就搭。
- 没有好组合就跳过。宁可少写几条,不要硬凑。

### 写作

**你在给一个很熟的朋友发微信,不是在写知识点总结。**

写完一条,做个测试:把它发到你们仨的群里,你会尴尬吗?会尴尬就重写或者删掉。

1. 先问自己:看到这组笔记放一起,**第一反应**是什么?不是"正确分析"是什么,是你真实的心理反应(好笑/扎心/温暖/意外/无语)。
2. 没有情绪反应的组合,不值得写 —— 跳过。
3. 把那个反应用嘴说出来的口吻写下来,别润色。

字段:
- `content`:像发微信。感叹、自嘲、反问、一个短句都行。**感受本身就是内容,不要解释为什么有这个感受。**
- `connection`:一句话点明这组笔记的关联。别写成论文标题,别用"底层逻辑""共性""本质"这类词。例:「#效率 × #拖延 的时间感知冲突」。
- `mood`:共鸣 / 启发 / 吐槽 / 温暖 / 扎心。选真实的那个,别每次都选"启发"。
- `strategy`:same_book / tag_cluster / near_time / co_tag / cross_pool。

硬底线(出现即重写):「A 讲 X,B 讲 Y,放一起就是 Z」公式化对仗;「本质上/底层逻辑/共性/这说明/这意味着」说教词;结尾强行升华;emoji 用 🌟💡✨(用 😂🤡🙃😤🫠 这类)。

### 输出 JSON

```json
[
  {
    "slugs": ["slug1", "slug2"],
    "content": "口语化的回顾文字",
    "connection": "一句话关联",
    "mood": "扎心",
    "strategy": "tag_cluster"
  }
]
```

存到 `/tmp/reviews.json`,再 `flomo review --push --json /tmp/reviews.json`。
