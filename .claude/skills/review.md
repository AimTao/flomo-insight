# Review Skill

当用户要求生成复习内容时使用此 Skill。

## 原理

两阶段 MCP 流程，全程 LLM 决策：

**Phase 1 — 概览**：`flomo_review_candidates()` 返回所有笔记池的轻量预览
（标签/内容摘要/标签分布），不做任何过滤。
**Phase 2 — 深潜**：对选中的池调用 `flomo_review_pool(strategy, label)` 获取完整笔记。

SQL 不做任何选择——全部交给 LLM 判断。

## 操作

```
1. 确保本地 DB 最新：flomo sync
2. （推荐）先了解近期思维模式：flomo_insight("topics")
3. Phase 1：MCP: flomo_review_candidates() → 看全局概览，挑选有潜力的池
4. Phase 2：对每个选中的池，MCP: flomo_review_pool(strategy, label) → 拿完整笔记
5. 阅读完整笔记，决定分组 + 写复习
6. 保存到 /tmp/reviews.json
7. 推送到 D1：flomo review --push --json /tmp/reviews.json
```

## 4 种策略

| 策略 | pool label | 含义 |
|------|-----------|------|
| same_book | 书名 | 同一本书的划线笔记 |
| tag_cluster | 标签名 | 同一标签下的笔记 |
| near_time | 日期 | 同一天写的笔记 |
| co_tag | "A × B" | 同时带两个标签的笔记 |

## 挑选标准

**值得深潜的池**：
- 标签虽然大，但 sample 显示内容有多个子主题可以交叉 → 值得看
- 标签小但很聚焦，sample 之间有化学反应
- 几个不同标签的 pool 之间可能有跨池关联 → 可单独拉出来分组
- 同一本书但不同章节的划线指向同一个问题

**直接跳过的池**：
- sample 全是流水账 / 随手记
- 标签很大但内容高度同质（例：30 条笔记全是「今天看到一篇 AI 文章」）

## 分组和写作要求

你是编辑 + 写作者。但要警惕：你是 AI，你的默认输出有 AI 味。这份指南就是为了压制它。

### 编辑 — 分组
- 仔细阅读每条笔记全文（Phase 2 不含截断）
- 找出真正有内在联系的笔记组合，不论条数
- 每条笔记只能出现在一个分组里
- 同一池内挑不出好组合就跳过，不要硬凑
- 大胆跨池组合

### 写作 — 核心原则

**你不是在写知识点总结，你是在发微信给一个很熟的朋友。**

写完一条复习后做这个检查：把这条消息发到你们三个人的群里，你会尴尬吗？会尴尬就重写。

### 写作 — 禁止清单

以下模式一旦出现，必删重写：

| 禁止 | 原因 |
|------|------|
| 「A 讲 X，B 讲 Y，放在一起就是 Z」 | 公式化，AI 味最重的结构 |
| 「本质上」「底层逻辑」「共性」「这说明」「这意味着」 | 说教信号词 |
| 「一个是xx，一个是xx」「既xx又xx」 | 对仗是演讲稿，不是聊天 |
| 结尾强行升华给人生道理 | 你在写作文，不是在聊天 |
| emoji 用 🌟💡✨（这些=AI） | 用 😂🤡🙃😤🫠 这类有人味的 |

### 写作 — 示范

**坏的（AI 味）**：
> 商业模式创新就是把被浪费的资源重新流动起来，而时间管理也是发现被浪费的时间段。这两条笔记都指向同一个底层逻辑：资源配置问题。

**好的（人味）**：
> 突然发现我对钱和对时间的态度一模一样——都在找那些「本来就属于我但被闲置了」的东西。车上空座=没用来学习的早上。懂了，我是个资源配置型人格。

**坏的（AI 味）**：
> 李飞飞说分类是连接一切研究的核心，而你在 flomo 里的标签系统也是在构建认知连接，二者共享同一个思维范式。

**好的（人味）**：
> 哈哈，我才意识到：我给每条笔记打标签的毛病，跟李飞飞给每张图做标注是一样的。原来我天天在用手工版 ImageNet。

**坏的（AI 味）**：
> 妄念有两种：做人的贪小便宜，做事的走捷径。这说明基本功才是最可靠的路径。

**好的（人味）**：
> 贪小便宜的最后被人利用，走捷径的最后绕回来补课。该挨的打一顿也少不了。想到自己上个月还试图三天学完 Rust……人确实不长记性。

### 写作 — 拿到一组笔记后，先问自己

1. 我看到这两条放在一起时，第一反应是什么？（不是「正确的分析」是什么，是真实的心理反应）
2. 这个组合让我觉得好笑/扎心/温暖/意外吗？如果没有情绪反应，这组就不值得写
3. 我会怎么用嘴说给朋友听？——把那个口吻写下来，别润色

### 字段说明

- `content`：像发微信。可以是感叹、自嘲、反问、一个短句。**不要解释为什么，感受本身就是内容。**
- `connection`：一句话点明关联，如「#效率 × #拖延 的时间感知冲突」。不要写成迷你论文标题。
- `mood`：共鸣 / 启发 / 吐槽 / 温暖 / 扎心。别全选「启发」——真实情绪是什么就选什么。
- `strategy`：same_book / tag_cluster / near_time / co_tag / cross_pool

## 输出 JSON

```json
[
  {
    "slugs": ["slug1", "slug2"],
    "content": "口语化复习文字",
    "connection": "一句话关联洞察",
    "mood": "共鸣",
    "strategy": "tag_cluster"
  }
]
```

保存到 `/tmp/reviews.json`。

## 推送到 D1

```
flomo review --push --json /tmp/reviews.json
```

首次推送 DROP + CREATE 新 schema（含 strategy/connection/mood），后续 INSERT。
