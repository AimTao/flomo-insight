# Insight Skill

当用户要求"洞察""分析笔记""看看最近在想什么"时使用此 Skill。

## 前置条件

```
flomo sync                           # 确保本地 DB 是最新的
```

## 洞察类型

### 分析型（5 种）—— 数据驱动，找规律

| 类型 | 用途 |
|------|------|
| `topics` | 思维全景：核心主题、思维模式、隐藏连接、缺失之处、精力分布 |
| `stagnant` | 停止更新的主题：哪些关注点被放弃/遗忘了 |
| `declining` | 热度下降的趋势：什么话题在减少，为什么 |
| `connections` | 标签共现网络：哪些主题经常一起出现，隐藏关联 |
| `draft` | 草稿型笔记：记了但没有深入展开的想法 |

### 视角型（6 种）—— 换角度解读

| 类型 | 用途 |
|------|------|
| `default` | 通用分析视角 |
| `value-clarification` | 价值观澄清：笔记中隐含的价值观和优先级 |
| `inversion` | 逆向思考：如果你想搞砸自己，该怎么做？反向推导你的盲区 |
| `second-order` | 二阶效应：每个想法/行为的连锁反应 |
| `cbt` | 认知行为疗法：识别认知扭曲和思维陷阱 |
| `mbti` | MBTI 视角：从人格类型角度解读行为模式 |

## 操作

```
1. flomo sync                         # 先同步
2. 调用 flomo_insight(type)           # MCP 工具，每次 1 种类型
3. 逐条阅读返回的 prompt + 笔记原文
4. 按 prompt 中的指令生成中文洞察报告（有判断，不客套）
```

## 常见洞察组合

- **定期复盘**：`topics` → `declining` → `stagnant`
- **深度自我觉察**：`cbt` → `value-clarification` → `inversion`
- **知识网络审视**：`connections` → `second-order` → `draft`
- **快速概览**：只跑 `topics`

## 注意事项

- 洞察数据来自**本地 SQLite**，不是实时 API。必须先 `flomo sync`
- 每次只调用一种类型，读完再换下一种（避免 prompt 太长）
- 洞察报告要有实质性判断，不要只是罗列笔记摘要
- 优先用中国用户熟悉的表达方式（西西弗斯、认知觉醒等概念直接引用）
