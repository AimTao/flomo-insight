# Tagging Skill

## 硬性规则：先确认，再写入

**禁止直接改标签或创建笔记。** 流程必须是：

1. 读取笔记 / 划线  
2. 给出**打标方案表**（slug、原文摘要、当前标签、建议标签、理由）  
3. **停下来等用户确认**（可整批确认或逐条改）  
4. 用户明确同意后，才执行 `flomo update` / `flomo create`  
5. 写入失败或用户否决 → 不要重试写入，按用户意见改方案  

用户若明确说「不用确认、直接改」，才可跳过第 3 步；否则默认必须确认。

## 标签分类体系（闭集优先）

优先从 `flomo_insight/tags/taxonomy.py` 中选：

- **生产力**：#效率 / #决策 / #习惯 / #学习 / #目标 / #专注 / #笔记术
- **心理**：#认知偏误 / #情绪 / #动机 / #自我认同 / #焦虑 / #社交 / #斯多葛
- **财富**：#投资 / #记账 / #商业 / #极简消费
- **人文**：#哲学 / #历史 / #文学 / #古诗 / #写作 / #社会学
- **生活**：#健康 / #关系 / #收纳 / #日常 / #早起 / #拖延
- **科技**：#AI / #编程 / #产品 / #工具
- **读书**：#书评 / #金句 / #书单 / #精读

**例外**：体系覆盖不了的明确主题可用 1 个短标签；禁止发明同义标签。

## 打标原则

1. 优先体系内标签，1–3 个  
2. 宁缺毋滥  
3. 同书/同主题多条笔记标签一致  
4. 微信读书导入必须带 `#微信读书`

## 微信读书导入

```bash
flomo import weread          # 输出划线+书评 prompt
flomo import weread --auto   # 仅 #微信读书，无 LLM（自动，不走确认）
```

LLM 导入流程：

1. 读 `flomo import weread` 输出  
2. **过滤**：纠错型 / 纯复述 / <5 字灌水 → 跳过  
3. 从 taxonomy 选 1–2 个标签  
4. **列出待导入清单**（书名、划线、书评、标签）→ **等用户确认**  
5. 确认后 `flomo create`（内容用 `<br>` 换行）  
6. `flomo weread-mark ...` 去重，直到无新划线  

## 重新打标（已有笔记）

```bash
flomo retag -n 10            # 只输出 tags_llm_at 为空的笔记（未 LLM 优化过）
flomo retag --all            # 强制含已优化的（少用）
```

本地字段 `memos.tags_llm_at`：`NULL` = 还没被 LLM 优化过；非空 = 已处理。

1. 读输出，按规则给出建议标签  
2. **方案表给用户 → 等确认**  
3. 确认后：`flomo update <slug> --content "..."`（正文含 #标签）  
4. 写成功后：`flomo tags-optimized <slug>`（可多个 slug）  
5. 写路径：先 flomo，成功后再镜像本地  

**不要**对已 `tags-optimized` 的笔记反复全量重打。

## 一致性

- 相似内容 → 相同标签  
- 禁止「一会儿 #商业 一会儿 #财富」这类同义漂移
